<!-- Salon Ru Zero One - Redesign Brief -->
# SALON APP - UI/UX REDESIGN BRIEF

**Application Name:** Salon Ru Zero One  
**Type:** Mobile-First PWA (Progressive Web App) for Salon Booking & Management  
**Target Users:** Salon Clients, Admin Staff, Salon Managers  
**Platform:** React 18 + TypeScript + Vite + Tailwind CSS  

## DESIGN SYSTEM SUMMARY
- **Primary Colors:** Emerald Green (#10B981), Teal (#14B8A6), Orange (#F97316)
- **Neutral Grays:** Dark (#1F2937), Medium (#6B7280), Light (#E5E7EB), Very Light (#F9FAFB)
- **Typography:** System fonts (sans-serif), 32px Hero Titles, 16px Body.
- **Components:** ServiceCard, AppointmentCard, StatCard, Emerald Primary Buttons.

## NAVIGATION
- **Top Bar:** Logo, Hamburger Menu (64px)
- **Bottom Nav:** Home, Services, Appointments, Queue, Profile (64px)

## CORE SCREENS
1. Home (Landing)
2. Services Catalog
3. Booking Flow
4. Appointments List
5. Live Queue
6. User Profile
7. Admin Dashboard
8. Admin Management (Appointments, Queue, Services, Users, Sessions)
